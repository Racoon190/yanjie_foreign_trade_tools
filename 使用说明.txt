言界 · 翻译 / DeepSeek / 汇率 / 世界时间 / 报价 / 社媒 便携版 v1.6.0
==============================================================

【怎么用】
1. 双击“言界-1.3.0-便携版.exe”即可运行，无需安装。
2. 首次启动需要联网，网页工作台会加载 Google 翻译、Wise 汇率和 World Clock。
3. 左侧切换“翻译 / 汇率 / 世界时间 / DeepSeek / 报价 / 社媒”，每个工作台会保留状态。
4. DeepSeek 默认走 API 对话，不用登录网页；点右上角“齿轮”填入 API Key 即可。

【DeepSeek API 对话（新）】
【已预置】本机已保存你的 API Key，首次启动会自动升级为系统密钥库（DPAPI）加密，
通常无需手动填写。如需更换：打开 platform.deepseek.com → API keys → 创建新 Key（形如 sk-...）。
2. 在言界“DeepSeek”页点右上角齿轮，粘贴 Key，点“保存设置”。
   可先点“测试连接”确认 Key 与网络是否正常。
3. Key 使用 Windows 系统密钥库（DPAPI）加密后保存在本机：
   %APPDATA%\YanJieData\deepseek-config.json
   界面与日志中都不会出现明文 Key，清除 Key 即彻底删除。
4. 模型可切换：
   · deepseek-chat      —— 通用对话，速度快，写邮件、翻译、算价都合适
   · deepseek-reasoner  —— 深度思考，会先给“思考过程”，适合复杂谈判方案
5. 对话支持流式输出、随时“停止”、多轮上下文、复制回答；记录保存在本机。
6. “带入报价摘要”会把当前报价单（客户、产品、成本、总额、毛利）附在问题里，
   让 AI 直接针对这份报价给建议。
7. 右上角“网页版”可切回 chat.deepseek.com 官方网页（需登录），两种模式互不影响。
8. 接口地址默认 https://api.deepseek.com。如需走自建/中转服务，可改成对应地址
   （必须 https；本机 http://127.0.0.1 调试地址允许）。

【报价（增强）】
1. 报价信息：客户、联系人、目的港、贸易术语、币种（USD/EUR/GBP/JPY/AUD/CAD/
   AED/SAR/RUB/CNY）、汇率、单号、日期、有效期。
   汇率是“1 外币 = ? CNY”，预设值只是参考，请按当天实际汇率修改。
2. 产品与成本：每个产品可选定价方式
   · 成本加成：填人民币成本，程序按成本占比分摊国内费用、海运费、保险费、
     其他费用与目标利润，自动算出报价单价。
   · 固定单价：直接填报价单价，程序按单价 × 数量计算，不再参与加成。
3. 若某行报价单价低于其单位成本，行内会出现红色“低于成本”提示。
4. 国内费用按人民币录入；海运费、保险费、其他费用按所选报价币种录入。
5. 折扣按小计百分比计算，毛利率 =（报价总额 − 总成本）/ 报价总额。
6. “导出语言”可选 中文 + English / 仅中文 / 仅 English，导出时只生成所选版本。
7. “复制摘要”把报价要点复制为纯文本，可直接粘贴到 WhatsApp 或邮件。
8. “存入报价库”保存当前版本（最多 30 份），点“报价库”可载入或删除历史版本。
9. 报价草稿自动保存在本机，关闭再打开会恢复上次内容。

【报价单导出】
1. 填写完成后点“导出 PDF”或“导出 Excel”。
2. 选择一次保存文件夹（下次会记住该文件夹），程序生成：
   · 报价单-客户-日期-中文.pdf / .xlsx
   · Quotation-Customer-Date-EN.pdf / .xlsx
3. PDF 为 A4 商务版式，Excel 可直接编辑（含产品、金额、条款）。

【提示】
· 翻译、汇率、世界时间是官方网站的桌面封装，必须联网使用。
· 报价计算、PDF / Excel 生成、对话记录都保存在本机；只有对话内容会发往
  你填写的 DeepSeek 接口地址。
· 用户数据（登录状态、缓存、报价草稿、报价库、API 配置、窗口位置）保存在：
  %APPDATA%\YanJieData
· 这是未购买代码签名证书的便携程序。Windows 首次运行时如出现 SmartScreen
  提示，请点击“更多信息” → “仍要运行”。
· 关闭主窗口即退出应用。

【首次运行的两个提示（正常现象）】
1. “Windows 已保护你的电脑 / SmartScreen”：本程序未购买代码签名证书，Windows
   不认识发布者。点“更多信息” → “仍要运行”即可，之后不再提示。
2. “NSIS Error: Error writing temporary file”：便携版是自解压包，需要先解压到
   %TEMP%\YanJieDesktop。若 360 等安全软件拦截未签名程序写入临时目录，就会报这个错。
   解决办法（任选其一）：
   · 直接使用免解包版：双击 win-unpacked 文件夹里的 言界.exe，不需要解压；
   · 或把便携版 EXE 加入 360「信任区」，并允许其写入 %TEMP%。

【数据目录（自动回退）】
应用会按以下顺序选择可写目录，前一个不可用就自动换下一个：
%LOCALAPPDATA%\YanJieData → %APPDATA%\YanJieData → 程序同级 YanJieData → %TEMP%
当前使用的目录会打印在启动日志里。即便安全软件拦截了 AppData，程序也能把配置、
报价草稿保存到程序旁边，不会闪退。

【如果双击后没有窗口】
1. 将便携版 EXE 加入 360 / Windows Defender 的信任区或白名单。
2. 重启一次 Windows，清除卡住的 Chromium 进程后再试。
3. 仍无窗口时，可双击 yanjie-app 文件夹里的“启动言界.cmd”排查。
   便携版启动器已内置兼容参数（--no-sandbox），用于绕过部分安全软件对
   Chromium 沙箱的拦截。

第三方网站：Google 翻译、DeepSeek、Wise、World Clock

【社媒（Facebook）】
左侧第 6 个“社媒”工作台直接加载 https://www.facebook.com/ ，与“翻译/汇率”等页签
共用同一份登录状态。
1. 首次进入点“登录”输入账号密码，之后重启应用保持登录。
2. 主页、Messenger、广告后台都在同一窗口内切换；Ctrl+6 可随时切回。
3. 需要在新窗口打开的链接（如广告管理平台）会自动交给系统浏览器。
4. 国内网络需先连 VPN/代理；若页面打不开会显示“Facebook 暂时无法打开”，
   可点“重新连接”，或“在浏览器中打开”用系统浏览器登录后回来。
5. 只想用网页版、不想装 VPN 时，可先用系统浏览器登录，再回到本页签刷新。

【社媒弹窗：确保这是你本人 / 请将安全密钥插入 USB 端口】
这是 Facebook 的"通行密钥（Passkey）"请求，不是病毒告警。Windows 规定只有签名
应用才能发起该请求，本程序未签名，于是弹出"未经验证的应用"提示。
1.4.0 起已内置拦截：页面调用通行密钥会被直接拒绝，弹窗不再出现，
Facebook 自动退回账号密码登录。
若你仍看到该弹窗：点“取消”即可，然后用邮箱/手机号 + 密码登录，功能不受影响。

【报价：实时汇率】
报价页“汇率”输入框右侧新增「实时汇率」按钮：
1. 点一下即从公开汇率接口（优先 wise.com 的实时中间价，每次并行取 9 个货币对；若被限流或断网，自动回退 open.er-api.com / frankfurter.app 的每日中间价）取 CNY 中间价，
   自动换算成 1 外币 = ? CNY，并同时更新全部 10 种币种。
2. 更新后输入框下方显示来源与时间，例如“实时中间价 · open.er-api.com · 10/28 17:53”。
3. 每次启动若上次更新超过 24 小时，会自动静默刷新一次；也可随时手动点按钮。
4. 接口不可用时会提示并保留你手填的数值，不影响报价。
5. 该数值为中间价，实际结汇请按银行报价加点。
